# 灵魂主题曲生成所
### Soul Theme Generator · 午夜营业中

> 回答三个小问题，我们把你的灵魂压成一张 lofi 卡带。

一个可以直接在浏览器打开的单文件交互网页作品。不依赖任何外部库、字体、图片、音频文件或网络请求——所有声音均由 Web Audio API 实时程序化合成。

## 一、创作理念（约 200 字）

每个人心里都有一段没法哼出来的旋律——它可能是凌晨三点的天花板、一场没下完的雨、或者某个再也没联系的人。「灵魂主题曲生成所」想把这种说不清的东西采样下来，压进一张 30 秒的 lofi 卡带里。

它假装是一间午夜营业的小作坊：先用六道温柔而奇怪的问题偷偷给你的人格称重（夜行性、浪漫浓度、混乱度、温柔值、怀旧感——但绝不告诉你算法），再用 8 次节拍点击测出你是抢拍还是拖拍的人，最后让你盲选一段音色。所有数据被揉进和弦、BPM、swing 和装饰音里，生成一首只属于你的曲子，连曲名都是现起的——《凌晨三点的自动贩卖机》《过期牛奶与月光》《电子羊的梦》……

lofi 的本质是"不完美的陪伴"：黑胶炒豆、磁带抖动、闷掉的高频。这恰恰像我们的灵魂——不完美，但值得被录下来循环播放。

## 二、玩法说明

### 环节 0 · 戴上耳机（交互入口）
双击打开 `index.html`，先看到"戴上耳机"的开场页。**点击「戴上耳机 · 开始采样」**——这一下既是仪式感，也是浏览器自动播放策略要求的首次用户交互，AudioContext 在此刻才被解锁。

### 环节 1 · 人格采样（6 道题）
温柔而奇怪的选择题，例如：

- 凌晨三点，你更可能在……（还在刷手机 / 刚写完点什么 / 在想某个人 / 在吃东西）
- 你手机相册里最多的是……（各种截图 / 天空 / 人和食物 / 备忘录截图）
- 如果灵魂有气味，你希望是……（雨后柏油路 / 旧书页 / 刚出炉的面包 / 雷电前的空气）

每个选项暗中给五个维度（夜行性 / 浪漫浓度 / 混乱度 / 温柔值 / 怀旧感）加不同的权重，界面上完全不提示。

### 环节 2 · 节奏测试（点击 8 次）
先听 4 拍节拍器"哒、哒、哒、哒"（80 BPM），然后跟着节拍点击圆盘 8 次。系统记录每次点击相对拍点的毫秒偏移：

- 平均偏移为负 → 你是**抢拍型**（最终 BPM 微升）
- 平均偏移为正 → 你是**拖拍型**（最终 BPM 微降）
- 离散度越大 → 最终曲子的 **swing 摆动感越强**

这个数据会真实写进主题曲，绝不浪费你的手滑。

### 环节 3 · 音色盲听（三选一）
三张卡片分别播放用 Web Audio 合成的短片段（C 大调琶音 + 一点点鼓）：

| 样本 | 实际音色 | 合成方式 |
|---|---|---|
| A 🎹 | 暖电钢 | 正弦 + 三角波叠加，快起缓落包络 |
| B 🎸 | 木吉他拨弦 | 锯齿波过动态低通，模拟拨弦 |
| C 🔔 | 颤音琴 | 正弦 + 4 次泛音 + 音量颤音 LFO |

选中的音色将成为你主题曲的主奏与和弦音色。可以反复试听。

### 终点 · 灵魂主题曲档案
生成动画后进入档案页：

- **卡带档案卡**：A 面写着曲名、BPM、和弦进行名；磁带卷随播放缓慢转动、左右卷此消彼长
- **播放控制**：播放/暂停按钮 + 音量滑块
- **翻面**：点击卡带或「翻面 B-SIDE」按钮，卡带 3D 翻转，播放同素材的**慢速变奏版**（BPM×0.85、八音盒主奏、极简鼓组、必有雨声）
- **人格成分表**：如「42% 夜行性 + 24% 怀旧感 + 18% 温柔值 + 9% 嘴硬 + 7% 维C」，最后一位是玩笑成分
- **五维雷达图**：Canvas 绘制，带入场展开动画
- **乐评人短评**：一句半温柔半毒舌的评语，如「把你的夜行性调成了可循环的和声。副歌缺席，但你会自己补上。」
- **规格徽章**：BPM / swing 百分比 / 主音色 / 调性 / 装饰元素一览

点「再测一次」重新开始（换答案就会得到不同的曲子、曲名和档案）。

## 三、技术实现说明

### 3.1 单文件架构
全部 CSS / JS 内联在一个 `index.html` 里，零外部依赖、零网络请求，双击本地即可运行。核心逻辑全部中文注释。

### 3.2 音频：Web Audio API 全程序化合成

**lofi 质感三件套（必有项）**

| 质感 | 实现方式 |
|---|---|
| 黑胶炒豆声 | 循环白噪声过高通（3.8kHz）做常驻沙沙底噪 + `setTimeout` 随机 60–320ms 触发的带通共振短脉冲（2.5–6kHz, Q=8）模拟"爆豆" |
| 磁带抖动 | 双层：全局 0.55Hz 正弦 LFO 调制总音量做"呼吸"；每个音符频率乘 `(1 + sin(t·2π·0.55)·0.004 + 随机微抖)` 做 wow & flutter |
| 低通"闷"感 | 全局 lofiBus 低通滤波（2.6kHz），所有乐器都过这条总线 |

**乐器（振荡器 + 包络）**

- 暖电钢：sine + triangle 叠加，两段指数衰减包络
- 木吉他：sawtooth 过"频率下扫的低通"，拨弦感来自极快起音（6ms）
- 颤音琴：sine 主体 + 4 倍频泛音 + 4.6Hz 颤音 LFO 调制音量
- 八音盒：sine 过高 Q 带通（Q=9），1.1 秒长衰减
- 贝斯：低频 sine + 包络
- 打击乐：底鼓 = 正弦 120→42Hz 下扫；军鼓 = 白噪声过高通 1.7kHz；闭镲 = 白噪声过高通 7kHz（全部噪声 buffer + 滤波合成）

**自动播放策略**：AudioContext 在开场页"戴上耳机"按钮的 click 事件里创建并 resume，符合浏览器手势解锁要求；页面隐藏或暂停后再次交互时调用 `resume()`。

**调度器**：look-ahead 模式——`setInterval` 每 180ms 醒来，把未来 1.2 秒内的所有小节按 `audioContext.currentTime` 精确铺进时间轴，保证 30 秒循环无缝且不受定时器抖动影响。

### 3.3 音乐生成算法

- **和弦进行**：内置 7 套进行（≥ 6 套要求），每套带人格匹配权重，五维得分加权求和 + 少量随机选出，再展开成 10 小节映射（4 和弦 ×2 遍 + 2 小节回转，约 30 秒一循环）
- **BPM（72–92）**：由"慵懒度"（夜行 + 怀旧 + 温柔 + 浪漫×0.5）决定基准，再按节奏测试的平均偏移微调（抢拍者微升）
- **Swing**：节奏离散度 + 拖拍倾向 + 混乱度共同决定（0.12–0.8），八分音符奇数步延后
- **旋律**：A 小调五声音阶随机游走 + 动机再现结构（开头陈述 2 小节动机 → 中段移高再现 → 其余小节按"混乱度→密度、温柔→级进"即兴填充）
- **曲名生成器**：4 套模板 × 多词库（时间/地点/形容词/名词两两组合），组合数远超 20 种，且人格数据影响选用哪套模板
- **乐评 & 成分表**：分句库随机组合；成分表取人格前四维 + 一个玩笑成分（嘴硬/维C/静电/旧电池……）按比例凑满 100%

### 3.4 视觉与交互

- **午夜窗台色调**：三层 radial/linear 渐变（深蓝紫夜空 + 右下角暖黄台灯光）+ 呼吸动画的暖光球
- **雨滴划过玻璃**：canvas 上 34 条斜向下落的短线，速度/长度/透明度随机
- **微灰尘颗粒**：42 颗暖色小点，正弦左右摆 + 缓慢下沉，亮度随相位闪烁
- **卡带**：CSS 3D transform 翻面（perspective + rotateY + backface-visibility），磁带卷用 repeating-radial-gradient 绘制辐条，播放时 CSS 动画旋转、宽度随播放进度此消彼长
- **雷达图**：Canvas 手绘五边形网格 + 渐变填充面 + `requestAnimationFrame` 入场动画
- **移动端适配**：viewport 锁定、`pointerdown` 统一处理触屏/鼠标、关键区域 `max-width`/`vmin` 响应式、600px 以下双列/单列自适应、`touch-action: manipulation` 消除点击延迟
- **无障碍小节**：尊重 `prefers-reduced-motion`
